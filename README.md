# 识字故事屋

给正在学认字的小朋友用的点读故事网页。故事全部用孩子已经学过的字编成，适合在 iPad 和手机上用。

- **32 个小故事，分六站，越读越长**：第一站「小芽」一页一句（最短 4 个字）；第二站「花朵」一页一两句；第三站「大树」一页两三句；第四站「果子」一页一段话（30–50 字），最后一关《一朵大花》是一页 51 个字、一口气读完的完整故事；第五站「小河」、第六站「大海」里可可自己出场，每关学 4–7 个新字。
- **点读**：点任何一个字就读出这个字，上方还会跳出一个大大的田字格字；点画里的小动物、东西，会读出它的名字。
- **整页朗读**：翻页后自动朗读（家长可以关掉），读到哪个字，哪个字就亮起来。
- **声音是录好的**：所有故事、每个字、表扬的话都提前录成了 mp3，**不依赖** iPad / 手机自带的语音，开着静音也能出声。整句是连起来读的，不是一个字一个字地念；点单个字时换一个单念更清楚的声音。
- **会动的绘本**：每页一个背景——飘动的云、下雨、闪电、星星、跑起来的火车、六一彩旗……
- **读完有奖励**：读完先做 3 道「听音找字」小挑战，然后跳出「可可，你真棒！」这样的表扬（10 句轮着说，每次不大一样，都会念出来），旁边是可可的照片，一直往上冒 👍 和 ❤️，点照片就给可可点个赞。闯过一站时换成可可的小视频。再拆礼物、得贴纸、得爱心。读完一关，下一关才打开。
- **宝箱**：收集到的贴纸、爱心奖章、可可的相册（可以点赞）；**字卡**：所有字的田字格卡片，点一下就念。
- **家长**：听一听（检查声音）、朗读速度、翻页自动朗读、音效、**可可的照片**（添加 / 删除）、**所有关卡都打开**、清空进度。

## 在 iPad / 手机上打开

网页是纯静态的，不需要服务器程序。最简单的办法是用 GitHub Pages：

1. 把这个分支合并到 `main`。
2. 在 GitHub 仓库里打开 **Settings → Pages**，Source 选 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，保存。
3. 一两分钟后会得到一个网址，在 iPad 的 Safari 里打开，点「分享 → 添加到主屏幕」，以后就像一个 App 一样全屏打开。

**没有声音？** 打开「家长 → 声音 → 听一听」：能听到就说明声音没问题。还听不到的话，把音量调大，看看是不是连着蓝牙耳机。第一次进来要先点一下屏幕，浏览器才允许出声。

进度（读到第几关、贴纸、爱心、点赞数）只存在这台设备的浏览器里。

## 可可的照片（不进 git）

这个仓库是公开的，所以**孩子的照片和视频没有放进仓库**：

- `media/` 文件夹在 `.gitignore` 里，不会被提交。里面放照片，再写一个 `media/media.js`：
  ```js
  window.KID = Object.assign(window.KID || {}, {
    photos: ['media/keke-1.jpg', 'media/keke-2.jpg'],  // 奖励页、相册里的照片（竖的 4:5 最好看）
    avatar: 'media/keke-avatar.jpg',                   // 首页左上角和故事里可可的头像
    video: 'media/keke-video.mp4', poster: 'media/keke-video.jpg',  // 闯过一站时放的小视频（可以不要）
  });
  ```
- 没有 `media/` 时网页照样能用：故事里的可可是一个写着「可可」的圆牌，奖励页只有表扬和礼物。
- 也可以在网页里加：「家长 → 可可的照片 → 添加照片」。这样加的照片只存在这台设备的浏览器里，不会上传。
- 孩子的名字在 `js/kid.js`，表扬的话在 `js/phrases.js` 的 `cheers`（改了要重新录音）。
- `node tools/build-single.mjs` 打包时会把 `media/` 里的照片和视频一起放进那个 HTML 文件，**发这个文件就等于发了照片**；不想带照片就加 `--no-media`。

## 学会新字以后

1. **加新字**：打开 `js/chars.js`，在 `CHAR_BATCHES` 末尾加一组：
   ```js
   { name: '识字启蒙 91–100', chars: '……' },
   ```
   这些字以后就不再算「新字」。
2. **加新故事**：在 `js/stories.js` 的 `STORIES` 末尾照着已有的格式加；文件开头写了背景、道具、动作都有哪些。可以开一个新的 `stage: 7`（第七站，记得在 `js/app.js` 的 `STAGES` 里加名字）。
3. **检查用字**：`node tools/check-stories.mjs`，会列出每个故事里不在已学字表里的字、每关多长、90 个字有没有都用到。
4. **录音**：`tools/gen-audio.py` 用开源的 Kokoro 中文语音模型（Kokoro-82M-v1.1-zh，Apache-2.0）把新的句子录成 mp3，只录新加的或改过的，准备步骤写在文件开头。整句、标题、词和表扬的话用声音 `zf_084`，一口气录下来（不是把单字拼起来），所以读起来是连贯的；每个字从第几秒开始也记下来，用来让字跟着亮。点一个字时念的单字用声音 `zf_003`：它单念一个字时更清楚、也慢一点。还没录音的句子会先用设备自带的语音读。多音字读错的地方加在 `js/chars.js` 的 `SAY_FIX` / `SAY_ALONE` 里。
5. **更新字体**：故事里出现了字体里没有的新字时，运行
   ```bash
   pip install fonttools brotli
   ```
   ```bash
   python3 tools/build-font.py
   ```
   （第一次会下载约 19MB 的原字体到 `tools/.cache/`，不进 git。）

也可以直接把新学的字拍照发给我，我来编新故事、录音。

## 文件

```
index.html            网页入口
css/style.css         样式、场景、动画
js/chars.js           已学会的字、要多练的字、多音字的念法
js/kid.js             孩子的名字（照片在 media/，不进 git）
js/stories.js         32 个故事（文字 + 每页的背景和图）
js/phrases.js         表扬的话（「可可，你真棒！」……）、点图片时念的词
js/audio-index.js     录音目录（自动生成）：每句话对应哪个 mp3、每个字从第几秒开始
audio/                录好的 mp3
js/scenes.js          会动的背景、画好的道具（山、房子、树、池塘、石头、大瓜、大花……）
js/audio.js           放录音（没有录音时用设备语音）+ 小音效
js/app.js             地图、读故事、小挑战、奖励（表扬、照片点赞）、宝箱、字卡、家长设置
media/                可可的照片和视频（只在本机，.gitignore 里）
fonts/kidkai.woff2    裁剪过的楷体（霞鹜文楷 GB，SIL OFL 1.1，许可见 fonts/OFL.txt）
tools/                检查故事、录音、裁剪字体、打包成单个 HTML 文件
```

打包成一个可以直接发送的 HTML 文件（录音也在里面）：`node tools/build-single.mjs`（输出到 `dist/`）。有 `media/` 时照片也会放进去，加 `--no-media` 就不放。
