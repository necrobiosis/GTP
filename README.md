# 识字故事屋

给正在学认字的小朋友用的点读故事网页。故事全部用孩子已经学过的字编成，适合在 iPad 和手机上用。

- **37 个小故事，分七站，越读越长**：第一站「小芽」一页一句（最短 4 个字）；第二站「花朵」一页一两句；第三站「大树」一页两三句；第四站「果子」一页一段话（30–50 字），最后一关《一朵大花》是一页 51 个字、一口气读完的完整故事；第五站「小河」、第六站「大海」里可可自己出场，每关学 4–7 个新字；第七站「好朋友」里可可的同学小爱、点点也来了，故事里用上了还没出现过的生字（兔 着 把 禾 厂 目）。
- **读新故事以前：先回顾，再自己挑生字**：
  1. **每日回顾**：读故事时求助过的字、读故事前说不认识的字、小测验没读出来的字，都放进「生字库」。读新故事以前先回顾：每个字先简单讲一句（比如「妈，女字旁加马，马马妈」），再听一听，在**十个字**里找出来（有几个长得很像），每个字要找对两次；点错两次会告诉孩子在哪里，这个字要再多对一次。回顾完才能读故事。认出来的字隔 1、2、4、7、15、30 天再拿出来；没认出来就从头再来。地图上的「📅 今日回顾」也能随时开始。
  2. **自己挑**：把故事里可能不认识的字列出来（五到八个：可可的生字、这一关第一次出现的字、前两关刚出现的字……），孩子自己点不认识的字（点了的字变粉、带一个问号），只学点了的字；都认识就直接读。上过课的字以后不再拿出来，不会重复。
  3. **上课**：老师的声音放慢了念，句子之间留停顿。有图的生字（可可的 32 个生字）七步：①**看一看**：一张大图，老师讲图里有什么；②**变一变**：象形字一笔一笔画出古时候的样子，再变成现在的字（眼睛 → 古时候的目 → 目），合起来的字拆开看（扌 手 + 丁 钉子 = 打）；③**读一读**：老师说这个字念什么，再念三遍；④**拆一拆**：每个部件一张小卡片，上面一幅会动的图、下面是部件和它的名字（☁️ 云 白云 + 💪 力 力气 = 动），卡片从它在字里的那一边飞进来（左边的从左边、上面的从上面），老师讲到哪个部件，哪张卡片就亮起来、跳一跳，最后合成大字（部首用橙色标出来）；再说是什么结构、部首是什么。讲法能讲来历的就讲来历（手里拿着一块肉，就是有），不好讲的编一个好记的小故事（天上的白云，被大力士用力一推，就动起来啦）。只有读音真的一样或者很像的部件才说「帮它读音」（马和妈），押韵的说「读起来有点像」（可和河），读音不像的（动里的云）不说，免得孩子糊涂；⑤**写一写**：田字格里一笔一笔演示，一边写一边说**笔画名称**（撇、竖、横折、横、横……），说「这个字一共几笔」，然后孩子用手指跟着描，描对一笔就说下一笔叫什么，描错了会提示；⑥**说一说**：三到五个词，每个词上面有一幅会动的图（白云 ☁️、小白兔 🐰、白雪 ❄️……），一个一个亮起来念；⑦**找一找**：**找五次**，选项从三个慢慢变成六个，长得像的越来越多。故事里别的字（一共 193 个字都有讲法）五步：读一读、拆一拆、写一写、说一说、找一找。学会一个字得 3 个金币。每日回顾时，每个字也会再看一眼部件的图（☁️云 + 💪力），讲一句。
- **先自己读，不会再求助**：打开故事、翻页都不出声，点字也不读，让孩子先自己读。不会读的字，点「求助」（举手的图标）→ 确认用 **5 颗爱心** → 点那个不会的字，**只读这一个字**，上方还会跳出一个大大的田字格字。求助过的字，这一关里再点就直接读，不再扣，还会放进「生字库」。爱心不到 5 颗时用掉剩下的，用完了求助不扣。点画里的小动物、东西，会读出它的名字。
- **爱心**：读完一关得这一关的爱心（第一、二站 3 颗，第三、四站 4 颗，第五站以后 5 颗），小挑战一次答对的再加；求助从攒下的爱心里扣 5 颗（挑字之前点「不用了」会还回来）。
- **金币和贴纸花园**：学会一个字 3 个金币，读完一关 5 个（全靠自己读再加 2 个），回顾一个字 1 个（今日回顾做完再加 2 个），过一站的小测验 15 个。读完故事得到的贴纸都在**贴纸花园**里：
  - **贴纸**带一圈白边、脚下有影子，有大有小（小虫小、水牛大，近大远小），自己走来走去（每一帧算位置，走得顺）、跳、转圈、打瞌睡；两个凑到一起会说话，吃的东西会被追着跑；多了会开派对、排队开火车。
  - **一起玩**：点一个贴纸说名字（小动物还会叫）；按住可以把它提起来放到别处；点一下空地，近的几个会跑过来；「🧺 喂一喂」把零食放到地上，贴纸跑来吃；贴纸还会自己跑到滑梯、喷泉、大树旁边玩。
  - **四个场景**：草地（本来就有）、海边 60、雪地 80、星空 100 个金币，左上角切换；每个场景有自己的背景（云、池塘、海浪、下雪、星星和流星），装饰摆在哪个场景就留在哪个场景。
  - **花园商店**分五类：花草、玩具、房子、零食（吃掉就没有了，2–5 个金币）、场景。买不起的会显示还差几个金币；买来的装饰种在地上（不带白边，和贴纸分得开），按「摆一摆」可以拖。以前买的东西都还在草地上。
  - 花园是另外加的，地图上的「宝箱」照旧。
- **多设备同步**（Netlify、Lovable 这两个公开网站上）：「家长 → 多设备同步」里，在有进度的设备上生成一个**同步码**，另一台设备（比如妈妈的手机）输入同一个码，两边的进度就合在一起，以后每次回到小路自动同步。读完的故事、学会的字、生字库取并集；爱心、金币、花园用最后改的那一台；声音、语速这些设置每台设备自己管。进度存在 Netlify 的一个小函数里（`netlify/functions/sync.mjs`，Netlify Blobs），知道同步码的人都能读写，同步码要像密码一样保管。claude.ai 页面里不用同步码：进度跟着 claude.ai 账号走。
- **学习报告**（家长设置最上面）：读完几个故事、多少字上过课、今天要回顾几个，还有最需要多练的十个字，点一个可以再上一次课。
- **每一站的小测验**：一站的故事读完了，地图上这一站最后有一个「📝 小测验」：用这一站学过的字编的新故事。孩子大声读，**家长在旁边**，读不出来的字点一下标红（同一个字只算一次，再点一下取消；不念出来）。不认识的字**不超过三个**就过关，下一站才打开；超过三个，这些字放进生字库，先去复习，再来考一次。以前已经读到后面几站的进度不会被锁回去。
- **身边的字**（地图最上面，主线以外）：我的名字（全名不写进公开的仓库：写在 `media/media.js` 的 `fullName`，或者在网页里填，只存在这台设备 / 自己的 claude.ai 账号里）、家人、好朋友、《冰雪奇缘》的字，点一个字就上课；还有自己写的小故事《我的名字》、一个很简单的《冰雪奇缘》（自己写的，没有用电影的台词和图）。大人、小朋友都可以**加字**（联网时会下载这个字的笔顺），也可以**写故事**（一行一页，没学过的字会提醒）；在 claude.ai 里还可以「✨ 请 Claude 帮忙编」，只用认识的字编一个。
- **家长陪读**（家长设置里打开）：故事页有「读一读」，可以整页朗读，读到哪个字，哪个字就亮起来；点字直接发音，不扣爱心。
- **声音是录好的**：所有故事、每个字、表扬的话都提前录成了 mp3，**不依赖** iPad / 手机自带的语音，开着静音也能出声。整句是连起来读的，不是一个字一个字地念；点单个字时换一个单念更清楚的声音，单字稍微拉长一点、收尾圆一点，听起来饱满。「可可」「跑跑」这样的名字按两个三声念（kě kě）。放在网上的版本会先把快要用到的录音下载好，点了马上响。
- **会动的绘本**：每页一个背景——飘动的云、下雨、闪电、星星、跑起来的火车、六一彩旗……
- **读完有奖励**：读完先做 3 道「听音找字」小挑战，然后跳出「可可，你真棒！」这样的表扬（10 句轮着说，每次不大一样，都会念出来），旁边是可可的照片，一直往上冒 👍 和 ❤️，点照片就给可可点个赞。闯过一站时换成可可的小视频。再拆礼物、得贴纸、得爱心和金币。读完一关，下一关才打开；一站的最后一关读完，先去考小测验。
- **生字库**：求助过的字、说不认识的字、小测验没读出来的字，分成「今天要回顾」和「认得了」（写着几天后再见）；点一个字再上一次课，「开始回顾」「再考一考」就是先讲一句、再十个字里找。地图上「生字库」按钮的小红点是今天要回顾的字数。
- **宝箱**：收集到的贴纸、爱心奖章、可可的相册（可以点赞）。
- **字卡**：可可的生字（点开就是上面那样的小课，认会了点「认识了」，以后读故事前就不再拿出来），还有所有字的田字格卡片，点一下就念。
- **家长**：听一听（检查声音）、**谁来读**（录好的声音，或者手机 / 平板自带的中文声音：iPhone / iPad 在「设置 → 辅助功能 → 朗读内容 → 声音 → 中文」里下载「高音质」的声音，比如「月」，这里就能选，高音质的排在最前面；自带的声音偶尔会把多音字念错）、朗读速度、**家长陪读**、**读故事前挑生字**、**每日回顾**、**读到哪一关**（换了设备或者进度没了时，选一关，前面的都算读完、前面几站的小测验算过了，从这一关接着读）、音效、**可可的照片**（添加 / 删除）、**所有关卡都打开**、清空进度。
- **进度存在哪里**：在 claude.ai 链接里打开时，进度存在自己的 claude.ai 账号里（换设备、App 清缓存也还在）；在 Lovable、Netlify 的网址上只存在那台设备的浏览器里，丢了可以用「读到哪一关」设回去。

## 在 iPad / 手机上打开

网页是纯静态的，不需要服务器程序。最简单的办法是用 GitHub Pages：

1. 把这个分支合并到 `main`。
2. 在 GitHub 仓库里打开 **Settings → Pages**，Source 选 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，保存。
3. 一两分钟后会得到一个网址，在 iPad 的 Safari 里打开，点「分享 → 添加到主屏幕」，以后就像一个 App 一样全屏打开。

**没有声音？** 打开故事以后本来就不出声（让孩子先自己读），点「求助」或者小挑战里才会读。检查声音：打开「家长 → 声音 → 听一听」：能听到就说明声音没问题。还听不到的话，把音量调大，看看是不是连着蓝牙耳机。第一次进来要先点一下屏幕，浏览器才允许出声。

进度（读到第几关、贴纸、爱心、点赞数）只存在这台设备的浏览器里。

## 公开网址（Lovable）

- **https://shizi-gushiwu.lovable.app** ：任何人都能打开，**没有可可的照片**。照片只在私密的 claude.ai 链接里；也可以在自己的设备上用「家长 → 可可的照片」加，只存在那台设备上。
- Lovable 项目里只有一个外壳网页 `public/app.html`，首页 `/` 会跳到它。样式、脚本、字体和录音都从 jsDelivr 读这个公开仓库某一次提交里的文件：`https://cdn.jsdelivr.net/gh/necrobiosis/GTP@<提交号>/…`。录音地址用 `window.AUDIO_BASE` 指过去。
- 改了故事或录音以后：先推送到 GitHub，再把 `public/app.html` 里的提交号换成新的（可以让 Lovable 的 AI 改，也可以在 Lovable 编辑器里改），然后点 Publish。`index.html` 里加了新的脚本时（比如认生字用的 `js/strokes.js`、`js/vendor/hanzi-writer.min.js`），`app.html` 里也要按同样的顺序加上。
- 每个网址各存各的：在 Lovable 网址上读到第几关、得了多少爱心、加了哪些照片，和 claude.ai 链接里的不通用。

## 公开网址（Netlify）

- **https://shizi-gushiwu.netlify.app** ：和 Lovable 上的一样，任何人都能打开，**没有可可的照片**。这里放的是网页文件本身（不经过 jsDelivr）。
- 更新：`node tools/build-site.mjs` 把网页文件复制到 `dist/site/`（不带 `media/`），再 `netlify deploy --prod --dir dist/site`。
- Netlify 免费版会在右下角加一个「Powered by Netlify」小标签。网页发现它以后，会把下面的字卡往上挪，免得盖住翻页按钮；小标签本身不去动它。想去掉，要在 Netlify 换付费版。
- 新建的网站默认要登录 Netlify 才能看；现在设成了只有预览版要登录，正式网址谁都能打开。

  ```js
    video: 'media/keke-video.mp4', poster: 'media/keke-video.jpg',  // 闯过一站时放的小视频（可以不要）
  });
  ```
- 没有 `media/` 时网页照样能用：故事里的可可是一个写着「可可」的圆牌，奖励页只有表扬和礼物。
- 也可以在网页里加：「家长 → 可可的照片 → 添加照片」。这样加的照片只存在这台设备的浏览器里，不会上传。
- 孩子的名字在 `js/kid.js`，表扬的话在 `js/phrases.js` 的 `cheers`（改了要重新录音）。
- `node tools/build-single.mjs` 打包时会把 `media/` 里的照片和视频一起放进那个 HTML 文件，**发这个文件就等于发了照片**；不想带照片就加 `--no-media`。

## 学会新字以后

1. **加新字**：打开 `js/chars.js`，在 `CHAR_BATCHES` 末尾加一组：
   ```js
   { name: '识字启蒙 91–100', chars: '……' },
   ```
   这些字以后就不再算「新字」。
2. **加新故事**：在 `js/stories.js` 的 `STORIES` 末尾照着已有的格式加；文件开头写了背景、道具、动作都有哪些。可以开一个新的 `stage: 7`（第七站，记得在 `js/app.js` 的 `STAGES` 里加名字）。
3. **检查用字**：`node tools/check-stories.mjs`，会列出每个故事里不在已学字表里的字、每关多长、90 个字有没有都用到。
4. **录音**：用微软 Azure 语音的神经网络声音「晓晓」（`zh-CN-XiaoxiaoNeural`）把新的句子录成 mp3，只录新加的或改过的：
   ```bash
   AZURE_SPEECH_KEY=你的密钥 AZURE_SPEECH_REGION=eastus python3 tools/gen-audio-azure.py
   ```
   **密钥只放在环境变量里**，不要写进任何文件、不要提交到 git（这个仓库和网站都是公开的，网页里也不放密钥：网页只放录好的 mp3）。全部重录一遍大约 3 万个字符，Azure 免费档每月有 50 万字。整句一口气录下来，读起来是连贯的；单个字指定拼音（`js/strokes.js` 里的 `CHAR_PY`），多音字、轻声不会念错；每个字从第几秒开始是从声音的停顿里算出来的，用来让字跟着亮。多音字在句子里读错的地方加在 `js/chars.js` 的 `SAY_FIX`（换成同音字）或者 `tools/gen-audio-azure.py` 的 `WORD_PY`（指定拼音）里。还没录音的句子会先用设备自带的语音读。
   `tools/voices.json` 的 `keep_original` 里写的话（现在是「小虫」「月儿」两个词）保留原来的声音：那是 `tools/gen-audio.py` 用开源的 Kokoro 中文语音模型（Kokoro-82M-v1.1-zh，Apache-2.0）录的，准备步骤写在文件开头；`engine` 是 `azure` 时它只录这几句，加 `--all` 可以全部换回 Kokoro 的声音。
5. **更新字体**：故事里出现了字体里没有的新字时，运行
   ```bash
   pip install fonttools brotli
   ```
   ```bash
   python3 tools/build-font.py
   ```
   （第一次会下载约 19MB 的原字体到 `tools/.cache/`，不进 git。）

也可以直接把新学的字拍照发给我，我来编新故事、录音。

打包成一个可以直接发送的 HTML 文件（录音也在里面）：`node tools/build-single.mjs`（输出到 `dist/`）。有 `media/` 时照片也会放进去，加 `--no-media` 就不放。录音太大、一个文件超过 16 MB 放不进 claude.ai 页面时，加 `--split-audio`：录音另外写成几个 `audio-data-N.js`，和网页一起发布。

用到的别人的东西：笔顺动画和手指描字用 [Hanzi Writer](https://hanziwriter.org) 3.7.2（MIT 许可，`js/vendor/LICENSE-hanzi-writer.txt`；改了一处：笔画遮罩的引用只写 `#id`，不带网页地址，不然在 claude.ai App 里笔画画不出来）；笔画数据来自 hanzi-writer-data 2.0.1（源自 Make Me a Hanzi，Arphic Public License，`js/vendor/ARPHICPL-hanzi-writer-data.txt`）；笔画名称来自 cnchar-order 3.2.6 的数据（MIT，`js/vendor/LICENSE-cnchar.txt`），按课本的叫法整理过（横钩/横撇、横斜钩/横折弯钩、女字旁的提、走之的平捺……），两份数据的笔顺也按每一笔的走向互相核对过；字体见上面。认生字的图、讲法、例词和老师说的话都是这里自己写的；`js/charinfo.js` 里每个字的结构和部件是这里自己整理的，拆字时参考过 Make Me a Hanzi 的字典（没有放进仓库）。《冰雪奇缘》的小故事是自己写的几句话，没有用电影的台词和图。
