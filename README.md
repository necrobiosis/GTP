# 识字故事屋

给正在学认字的小朋友用的点读故事网页。故事全部用孩子已经学过的字编成，适合在 iPad 和手机上用。

- **16 个小故事，分三站，越读越长**：第一站「小芽」一页一句（最短 4 个字），第二站「花朵」一页一两句，第三站「大树」一页两三句。
- **点读**：点任何一个字就读出这个字，上方还会跳出一个大大的田字格字；点画里的小动物、东西，会读出它的名字。
- **整页朗读**：翻页后自动朗读（家长可以关掉），读到哪个字，哪个字就亮起来。
- **会动的绘本**：每页一个背景——飘动的云、下雨、闪电、星星、跑起来的火车、六一彩旗……
- **读完有奖励**：读完先做 3 道「听音找字」小挑战，然后拆礼物、得贴纸、得爱心，点屏幕还会冒出爱心。读完一关，下一关才打开。
- **宝箱**：收集到的贴纸和爱心奖章；**字卡**：90 个字的田字格卡片，点一下就念。

## 在 iPad / 手机上打开

网页是纯静态的，不需要服务器程序。最简单的办法是用 GitHub Pages：

1. 把这个分支合并到 `main`。
2. 在 GitHub 仓库里打开 **Settings → Pages**，Source 选 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，保存。
3. 一两分钟后会得到一个网址，在 iPad 的 Safari 里打开，点「分享 → 添加到主屏幕」，以后就像一个 App 一样全屏打开。

**朗读用的是设备自带的中文语音。** 如果点字没有声音：iPad / iPhone 打开「设置 → 辅助功能 → 朗读内容 → 声音 → 中文」，下载一个声音（婷婷之类）。安卓手机一般自带。打开「家长」可以选声音、调语速。

进度（读到第几关、贴纸、爱心）只存在这台设备的浏览器里。

## 学会新字以后

1. **加新字**：打开 `js/chars.js`，在 `CHAR_BATCHES` 末尾加一组：
   ```js
   { name: '识字启蒙 91–100', chars: '……' },
   ```
   这些字以后就不再算「新字」。
2. **加新故事**：在 `js/stories.js` 的 `STORIES` 末尾照着已有的格式加；文件开头写了背景、道具、动作都有哪些。可以开一个新的 `stage: 4`（第四站）。
3. **检查用字**：`node tools/check-stories.mjs`，会列出每个故事里不在已学字表里的字、每关多长、90 个字有没有都用到。
4. **更新字体**：故事里出现了字体里没有的新字时，运行
   ```bash
   pip install fonttools brotli
   ```
   ```bash
   python3 tools/build-font.py
   ```
   （第一次会下载约 19MB 的原字体到 `tools/.cache/`，不进 git。）

也可以直接把新学的字拍照发给我，我来编新故事。

## 文件

```
index.html            网页入口
css/style.css         样式、场景、动画
js/chars.js           已学会的字、要多练的字、单字发音修正
js/stories.js         16 个故事（文字 + 每页的背景和图）
js/scenes.js          会动的背景、画好的道具（山、房子、树、池塘、石头、大瓜……）
js/audio.js           中文朗读 + 小音效
js/app.js             地图、读故事、小挑战、奖励、宝箱、字卡、家长设置
fonts/kidkai.woff2    裁剪过的楷体（霞鹜文楷 GB，SIL OFL 1.1，许可见 fonts/OFL.txt）
tools/                检查故事、裁剪字体、打包成单个 HTML 文件
```

打包成一个可以直接发送的 HTML 文件：`node tools/build-single.mjs`（输出到 `dist/`）。
